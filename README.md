# Stoney’s Terminal Tools 🧠⚡

A growing collection of custom Bash scripts for:

- System monitoring
- Session tracking
- Network visibility & LAN device discovery
- System maintenance

## 🔧 Included Tools

### `net-scry`
Scans local LAN for devices, hostnames, and open ports

### `syswatch`
Prints system health: CPU, RAM, disk, uptime, network

### `session-time`
Displays how long you've been logged in

### `groundwork`
Handles system updates, upgrades, and cleanup — keeps the machine current and clear
